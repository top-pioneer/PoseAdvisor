# PoseAdvisor 智能拍照姿势顾问 · 软件说明书

**版本：V1.0**
**运行环境：Android 8.0（API 26）及以上**

---

## 1. 软件概述

PoseAdvisor（姿势顾问）是一款端上实时的拍照姿势推荐与引导软件。软件在相机取景过程中实时检测被摄者的人体姿态，从内置姿势库中推荐适合当前场景的拍照姿势，以半透明"幽灵骨架"形式叠加显示在取景画面上，并对被摄者当前姿势进行逐肢体段的匹配度评分与纠正提示，帮助用户在按下快门前摆到最佳姿势。软件采用零快门延迟成像架构，按下快门即可瞬间完成拍照。

## 2. 主要功能

### 2.1 实时取景
启动软件后进入相机取景界面，画面全屏显示，支持前后摄像头切换。

### 2.2 场景感知推荐
软件自动对取景画面进行轻量统计分析（亮度、植被颜色占比、天空占比），毫秒级识别"户外自然""开阔天空""室内弱光""明亮通透""日常街拍"等场景类型，并自动切换到与之匹配的姿势类别。用户也可点击右下角场景按钮随时重新识别。

### 2.3 姿势库浏览与选择
界面底部为姿势推荐卡条，按"气质站姿 / 坐姿低机位 / 手势特写 / 舒展动态"四大类别组织，每类 10 组姿势。点击类别标签切换类别，左右滑动浏览姿势卡片，点击卡片将其设为引导姿势。全部姿势由场景条件变分自编码器（VAE）离线生成并精修入库，共 40 组。

### 2.4 幽灵骨架引导
选中的引导姿势以半透明蓝色骨架形式叠加在取景画面中央，被摄者只需对照骨架调整自己的站位与肢体。

### 2.5 实时匹配反馈
软件以约每秒 10 次的频率检测被摄者姿态（MediaPipe PoseLandmarker 端上推理，不经过网络），与引导姿势进行尺度、位置无关的归一化比对：
- 骨架逐肢体段着色：达标肢体显示青色，偏差肢体显示橙色；
- 右上角显示 0–100 的整体匹配度评分；
- 自动定位偏差最大的肢体段，弹出方向性纠正提示（如"请把左前臂向上调整"）；
- 匹配度达到 85 分以上时提示"姿势很棒，可以拍了！"。

### 2.6 零快门延迟拍照
点击快门按钮，软件直接从内存中的最新预览帧编码生成照片（无需相机二次曝光捕获），从按下到完成通常在 200 毫秒以内，彻底消除传统拍照的快门迟滞。照片自动保存到系统相册 `Pictures/PoseAdvisor` 目录，左下角出现照片缩略图，点击可调起系统图片查看器。

## 3. 使用流程

1. 打开软件，授予相机权限；
2. 将镜头对准拍摄环境，软件自动识别场景并给出推荐姿势类别；
3. 在底部卡条中挑选喜欢的姿势；
4. 被摄者走入画面，对照半透明骨架调整姿势，观察匹配度评分与纠正提示；
5. 匹配度满意时按下快门，照片即时保存。

## 5. 隐私与安全

- 软件全部计算（姿态检测、姿势比对、场景识别、拍照成像）均在设备本地完成，不经过任何网络传输；
- 软件仅申请相机权限（Android 8.0–9.0 设备额外需要存储权限用于保存照片）；
- 不收集、不上传任何用户数据。

## 6. 技术要点

- CameraX 预览帧流与零快门延迟成像架构；
- MediaPipe PoseLandmarker 端上实时人体姿态关键点检测（GPU 委托优先、CPU 兜底）；
- 33 关键点 → 25 关节 75 维向量的训练对齐映射；
- 骨盆对齐 + 躯干长度归一化的尺度/位置无关姿势比对算法；
- 场景条件 VAE 离线姿势生成与 K-Means 聚类 + 最远点采样的姿势库筛选管线。
