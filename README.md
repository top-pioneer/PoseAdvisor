# 场景感知姿势推荐系统

基于深度学习的人体姿势生成与3D重建系统，能够根据输入场景图片自动生成合理的人体姿势。

## 项目概述

本系统采用**场景条件变分自编码器（Scene-Conditioned VAE）**架构，通过分析场景图像特征，生成与场景匹配的人体姿势，并进一步重建为3D人体模型。

## 核心功能

- **场景感知姿势生成**：输入任意场景图片，自动生成8种与场景匹配的人体姿势
- **3D人体模型重建**：将生成的姿势拟合为高质量SMPL-X人体网格模型
- **多姿态输出**：单次运行生成多种姿势选项供用户选择
- **完整可视化**：包含姿势骨架和3D模型的可视化输出

## 技术架构

                          │

┌─────────────────────────────────────────────────────────────┐

                          │

## 快速开始

### 环境要求

- Python 3.8+
- PyTorch 2.0+
- (推荐使用GPU加速)

### 准备数据

1. 将场景图片放入 `demo/input/` 目录
2. 支持格式: `jpg`, `jpeg`, `png`, `bmp`

### 获取 SMPL-X 模型

本项目需要 SMPL-X 人体模型文件才能运行：

1. 访问 [SMPL-X 官方网站](https://smpl-x.is.tue.mpg.de/)
2. 注册账号并下载 SMPL-X 模型（选择 neutral 模型即可）
3. 解压后将 `smplx` 目录放到以下位置：

```
Project1/
└── model/
    ├── latest.pth           # VAE 模型
    └── smplx/              # SMPL-X 模型目录
        ├── SMPLX_NEUTRAL.npz
        └── ...
```

### 运行完整流程

```bash
python scripts/run_full_pipeline.py
```

### 输出结果

运行完成后，输出文件位于 `outputs/{图片名}/` 目录下：

```
outputs/{图片名}/
├── poses/
│   ├── {图片名}_generated.npy      # 生成的8组75维姿势向量
│   └── {图片名}_generate_skeleton.png  # 姿势骨架可视化
└── smplx/
    ├── {图片名}_fit_0.obj          # 第1个姿势的3D模型
    ├── {图片名}_fit_0_params.npz   # 模型参数
    ├── ...
    └── {图片名}_fit_7.obj          # 第8个姿势的3D模型
```

## 模型架构

### Scene-Conditioned VAE

| 组件        | 描述                       |
| --------- | ------------------------ |
| **编码器**   | 3层全连接网络，将75维姿势编码为64维潜在向量 |
| **解码器**   | 3层全连接网络，结合场景特征解码为75维姿势   |
| **场景编码器** | CLIP ViT-B/32，提取图像的视觉特征  |
| **潜在空间**  | 64维高斯分布                  |

### SMPL-X 拟合

| 参数           | 值    |
| ------------ | ---- |
| **优化步数**     | 700  |
| **学习率**      | 0.01 |
| **姿态正则化**    | 0.03 |
| **Stage1比例** | 0.55 |
